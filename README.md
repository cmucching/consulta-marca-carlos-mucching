# Consulta de identidad tipográfica

Página de muestras para la consulta de Carlos Mucching. GitHub Pages presenta las alternativas; Google Forms centraliza votos y comentarios. Los datos de respuesta no se guardan en este repositorio.

El paisaje y la firma son comunes a las cuatro alternativas. Los códigos01–04 permanecen fijos; cuatro versiones alternan el orden de presentación.

Imágenes conceptuales de marca. Material de evaluación, sin declaración de identidad definitiva.
